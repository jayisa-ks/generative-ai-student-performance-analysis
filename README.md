# generative-ai-student-performance-analysis
This end-to-end Data Analytics project explores the impact of Generative AI on student academic performance and learning outcomes. The project combines Python, MySQL, and Power BI to analyze AI usage patterns, GPA improvement, skill retention, exam anxiety, and burnout risk among students.

The objective is to demonstrate a complete data analytics workflow, from raw data processing to interactive dashboard development.

##  Tools & Technologies
- Python
- Pandas
- Jupyter Notebook
- MySQL
- Power BI

  ##  Project Workflow

  ### 1. Data Collection
- Imported student AI usage dataset.

### 2. Data Cleaning
- Handled missing values.
  Created additional analytical columns:
  - **GPA_Improvement** = Post GPA − Pre GPA
  - **Burnout_Risk_Level** based on burnout score categories (Low, Medium, High)
- Exported the cleaned dataset for further analysis.

### 3. Exploratory Data Analysis (EDA)
- Analyzed AI usage patterns.
- Studied GPA changes before and after AI adoption.
- Explored skill retention and learning outcomes.
- Investigated exam anxiety and burnout risk.

### 4. SQL Analysis
- Performed business-style analytical queries.
- Identified factors influencing academic improvement.
- Measured relationships between AI dependency and performance metrics.

### 5. Power BI Dashboard
- Created an interactive one-page dashboard.
- Added KPIs, charts, slicers, and bookmark-based filter panel.
- Designed a professional reporting layout.

### Dashboard KPIs
- Total Students
- Average Pre GPA
- Average Post GPA
- Average GPA Improvement
- Average Skill Retention Score

## 📈 Key Insights

- Moderate AI usage resulted in the highest GPA improvement.
- Excessive AI dependency reduced skill retention.
- Advanced prompt engineering skills led to better academic outcomes.
- Higher AI usage was associated with increased exam anxiety.
- A significant percentage of students were identified as medium or high burnout risk.
